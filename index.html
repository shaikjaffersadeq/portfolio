PROJECT 01 • SOC INVESTIGATION

Network Reconnaissance Investigation

Suspicious Web Reconnaissance Detection & Investigation

Severity: Medium • Status: Investigated

A controlled SOC laboratory investigation of suspicious automated web reconnaissance originating from 192.168.56.103 against the laboratory web server at 192.168.56.102:8000.

Source
192.168.56.103
Target
192.168.56.102:8000
Detection Indicator
SQLMap User-Agent
Access Result
HTTP 404 on /admin

Investigation Performed

  • Analyzed network traffic using Wireshark.
  • Reviewed TCP SYN, SYN/ACK and RST traffic.
  • Inspected HTTP requests and responses.
  • Identified the SQLMap User-Agent as a suspicious detection indicator.
  • Investigated the /admin request.
  • Confirmed the server returned HTTP 404.
  • Found no evidence of successful administrative access.
  • Created IOCs and incident documentation.
  • Created a Sigma-style detection rule.
  • Produced a complete SOC investigation report.
