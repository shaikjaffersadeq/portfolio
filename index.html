PROJECT 02

SOC Brute-Force Login Detection & Investigation

Investigated repeated failed SSH authentication attempts in an isolated SOC laboratory environment using Kali Linux and Ubuntu Linux.

Authentication logs were analyzed to identify the source IP, destination system, target account and authentication timeline. The investigation also correlated failed attempts with successful-login events.

SSH Linux Log Analysis IOC Analysis Detection
Finding: Three failed SSH authentication attempts were identified from the same source against the snowden account. No successful authentication was observed immediately after the controlled failed-login sequence.
