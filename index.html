SOC Incident Investigation

Suspicious Web Reconnaissance

Built an isolated Kali Linux and Ubuntu environment to investigate suspicious HTTP reconnaissance activity. Network traffic was generated, captured and analyzed using Nmap, tcpdump and Wireshark.
